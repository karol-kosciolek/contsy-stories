# Model and tool sources

Weights are downloaded separately, not included with the application. `config/models.json` and `config/auxiliary-models.json` record the exact repository revisions, filenames, sizes and SHA-256 hashes of every file. Every file comes from the model authors' own repositories, or from the quantized conversions named below; the original model authors' terms apply to those too. Where an official file has another format than the engine reads, the installer converts it on your PC with Contsy's own code and checks the result against the SHA-256 in the catalog. Settings lists the same download sources and license notes.
